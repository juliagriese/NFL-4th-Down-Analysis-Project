# NFL-4th-Down-Analysis-Project
An analysis of NFL 4th down attempts over the past 24 seasons using the NFL Team Stats 2002 - Feb. 2026 (ESPN) dataset obtained through Kaggle. Project completed for CMSE 201.

"CMSE_4thDownAnalysis_Griese.ipynb" - Analysis code file
"4thDownAnalysis_ppt" - PowerPoint with visualizations and findings
